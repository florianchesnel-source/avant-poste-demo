# Avant-Poste : démo

Démo jouable d'Avant-Poste, un FPS/TPS de science-fiction de Walkore : un débarquement sur une plage contre une nuée
d'insectes, jusqu'à la brèche dans la muraille de la ruche.

**Jouer :** https://florianchesnel-source.github.io/avant-poste-demo/ (Chrome, Edge ou Firefox, sur ordinateur).

Commandes : ZQSD ou WASD pour se déplacer, clic gauche pour tirer, clic droit pour viser, R pour recharger,
G pour une grenade, Échap pour la pause. F3 affiche la qualité graphique choisie et les temps d'image.

Ce dépôt ne contient que le jeu construit (`index.html`), pas le code source.
